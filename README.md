# 800×800 电商主图裁剪工具

一个纯浏览器运行的图片裁剪工具，专门用于把商品图片处理成标准 800×800 电商主图。

## 功能

- 支持 JPG / PNG / WEBP
- 支持一次上传多张图片
- 输出固定 800×800
- 裁剪填满模式
- 完整保留 + 白底补边模式
- 鼠标/触控拖动调整主体位置
- 缩放调整
- JPG 95% 质量导出
- PNG 无损导出
- 批量下载
- 所有图片均在浏览器本地处理，不上传服务器

## 本地使用

直接双击 `index.html` 即可在浏览器中打开。

## GitHub Pages 部署

1. 打开仓库 `Settings`
2. 进入 `Pages`
3. 在 `Build and deployment` 中选择 `Deploy from a branch`
4. Branch 选择 `main`
5. Folder 选择 `/ (root)`
6. 点击 `Save`

部署完成后即可通过 GitHub Pages 网址在线使用。
