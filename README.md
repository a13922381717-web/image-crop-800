# 电商图片工具

基于原有 800×800 电商主图裁剪工具，扩展为带独立功能菜单的电商图片工作台。前端使用 HTML / CSS / JavaScript，裁剪、排版和批处理在浏览器本地完成。AI 模特与场景通过可选的本机 Node.js 服务连接 OpenAI，点击 AI 生成才上传参考素材并产生 API 费用。在线翻译为按需使用的文案服务。

## 功能菜单

电脑端使用深色左侧菜单，手机端点击“功能菜单”展开。每个入口对应可实际操作的工具：

| 功能 | 用途 |
| --- | --- |
| 800×800 主图裁剪 | 原有拖动、缩放、白底补边与批量保存 |
| AI 模特与场景 | 同款产品换模特 / 场景，样图确认、套图、实拍细节图及 ZIP |
| 模板详情图生成 | 生成 5 张 800×1200 详情图，不含尺码表 |
| 详情图英文翻译 | 翻译或手动填写英文，导出英文详情图 |
| 批量生成 3:4 长图 | 输出 900×1200，完整显示或居中裁剪 |
| 批量 800×800 PNG | 统一方图，支持透明或纯色补边 |
| 批量调整尺寸 | 自定义宽高，按比例补边或裁剪 |
| 图片压缩与格式转换 | 调整最长边、质量，转换 JPG / PNG / WebP |
| 商品拼图与长图拼接 | 2–4 列网格拼图或竖向拼接 |
| 批量添加文字水印 | 设置文字、位置、颜色、字号、透明度，支持平铺 |
| 去水印 / 局部修补 | 框选区域，以周边颜色修补或干净区域取样覆盖；支持撤销、对照和原尺寸下载 |
| 批量纯色背景替换 | 替换与边缘连通的相近颜色，输出纯色或透明背景 |

## 批量图片处理

1. 从菜单打开任意批量工具，上传 JPG / PNG / WebP。七个批量工具共用一个素材列表，最多 20 张，可上移、下移、删除；拼图按列表顺序排列。
2. 每张图片最多 20 MB、3200 万像素、最长边 12000 px。工作副本最长边为 2400 px，原文件不变；后续放大不会恢复被缩小的细节。
3. 设置当前工具的参数、格式及质量，点击“生成预览”。结果显示尺寸、文件大小及与原文件的大小比较；压缩后文件也可能变大。
4. 点击图片放大检查，支持单张下载、ZIP 打包下载、保存到文件夹。预览和下载使用同一份结果；每次文件夹导出创建独立子文件夹。
5. 切换批量工具保留各自参数和结果。修改参数后，当前结果需重新生成；更改共享素材后，所有批量工具的旧结果需重新生成。清空素材也会清空这些工具的结果。

读取和生成支持取消；处理期间需完成或取消后才能切换功能。自定义尺寸最大单边 8192 px、总像素 1200 万；拼接长图最大高度 16000 px、总像素 1200 万，超限会提示缩小输出宽度或减少素材。

透明补边不会移除图片原有背景；JPG 不支持透明，会以白色合成。纯色背景替换适合白底或其他单色背景，只处理从边缘连通的区域，保留封闭区域及已有透明度，不提供复杂背景的智能抠图。本节的批量工具均不接 AI API。

## 去水印 / 局部修补

从菜单打开工具，拖入一张 JPG / PNG / WebP，在预览上按住拖动框选水印。简单背景使用“周边颜色修补”；纹理区域选择“取样覆盖”，再点“选取干净区域”，在图中点击合适的位置。水印周围留少量边距，可调整边缘融合、放大检查、对照原图、撤销最近 5 步或恢复原图。

在本机处理，不需要 API 或上传图片到服务器。每张最多 20 MB、1200 万像素，单次修补最多 200 万像素。保留原始尺寸和选区以外的像素，下载 PNG 或白底 JPG。此功能使用局部颜色插值和取样复制，不能保证还原被遮挡的产品纹理。刷新或替换图片前请先下载结果。

## 主图裁剪

保留原有功能：多图上传、800×800 裁剪填满、完整保留与白底补边、鼠标/触控拖动、缩放、自动居中、移除图片、JPG 95% / PNG 导出、选择保存文件夹和批量保存。切换到详情图工具后再返回，当前图片、位置、缩放和保存位置保持不变。

## 详情图生成

1. 切换到“详情图生成”，上传产品图，也可以直接使用主图工具中当前的裁剪结果。
2. 可选上传细节图。产品图和细节图各最多 6 张，支持 JPG / PNG / WebP，每张不超过 20 MB、3200 万像素、最长边 12000 px。大图在工作副本中缩小至最长边 2400 px，原文件不变。
3. 填写产品名称、可选副标题，以及 1–4 条卖点（每行一条，每条最多 100 字）。无需尺码数据。
4. 选择极简黑白、暖沙米色或清新草绿，点击生成。
5. 自动生成 5 张 **800×1200** 图片：产品封面、核心卖点、细节展示、多角度展示、产品总览。点击预览可放大查看或单张下载。
6. 选择 JPG 或 PNG，打包下载 ZIP，或者保存到所选文件夹。每次文件夹导出会创建独立批次子文件夹，避免覆盖已有文件。

素材保持原比例、完整显示；无细节图时使用产品图，只有一张产品图时会复用并提示。模板只使用填写的文案，不自动编造产品承诺。长文案会自动换行、缩小，局部摘要空间不足时显示省略号，请放大检查成图。修改素材、文案或配色后，需要重新生成才能导出，避免下载旧内容。

文件夹选择需要浏览器支持 File System Access API（如新版桌面 Chrome / Edge）及安全环境；不支持时可使用 ZIP 下载。所有导出都是重新编码的图片。刷新或关闭页面会清除素材和生成结果，请及时导出。

## 英文详情图

1. 打开“详情图英文翻译”，或将“详情图语言”切换为“英文详情图”。
2. 点击“将中文文案翻译成英文”，翻译产品名称、副标题和每条卖点。中文原文保留；也可不使用翻译服务，直接填写英文。
3. 核对、编辑英文文案，再点击“生成 5 张英文详情图”。标题、页脚、细节编号和导出文件名也会使用英文。
4. 支持英文版 JPG / PNG、单张下载、ZIP 和保存到文件夹。英文名称最多 120 字符、副标题最多 180 字符，每条卖点最多 240 字符；超过限制的译文会完整保留供精简，不会暗中截断输入。

在线翻译仅在点击翻译按钮后请求 [MyMemory 官方翻译接口](https://mymemory.translated.net/doc/spec.php)，只发送填写的文案，不发送图片，不需要 API 密钥。该服务可能留存文案，使用前请阅读 [服务条款](https://mymemory.translated.net/terms-and-conditions)。[匿名免费额度](https://mymemory.translated.net/doc/usagelimits.php)当前为每天 5,000 字符；网络失败、服务限流或超时会给出提示，可以重试或手动填写英文。

翻译可以取消；任何一段失败或取消，都不会覆盖之前的英文。成功译文只在当前页面内存中缓存，刷新后清除。中文原文修改后，需重新翻译，或核对并保留当前英文，才能生成新版英文图片。

此功能翻译填写的文案和模板文字，不识别、擦除或替换上传图片中已经印好的文字。

## 本地使用

下载整个仓库，保留 `index.html` 和同目录的全部 `.js`、`.css` 文件，双击 `index.html` 即可使用本地图片工具。AI 生成功能需按下节启动本机服务。刷新或关闭页面会清除当前素材、参数和结果，请先导出。

## AI 模特与场景

1. 安装 Node.js 22 或更新版本（本机已有 Codex 提供的 Node 时，启动器会尝试使用它）。macOS 双击 **启动电商图片工作台.command**；也可在项目目录执行 `node ai-server.cjs`，打开 `http://127.0.0.1:8787/?tool=ai`。保持终端窗口运行。
2. 展开「图片 API 配置」，填入自己的 OpenAI API Key，点击「连接」。密钥只保存到本次 Node 服务内存，关闭服务即清除；不要把真实密钥写进仓库。也支持通过环境变量 `OPENAI_API_KEY` 配置，默认模型 `gpt-image-2`，可通过 `OPENAI_IMAGE_MODEL` 修改。连接时不调用付费 API，首次生成才验证额度和模型权限。
3. 将同款产品实拍拖到「产品素材」上传框，或点击选择文件；支持多张拖入，最多 8 张，每张 20 MB / 4000 万像素以内。拖入不支持的文件会提示，处理期间禁止追加素材。第一张默认标记正面，其余默认细节，请手动选择背面和侧面。发送给 AI 的工作副本最长边为 1600 px，原文件不变。模特或风格参考图可选 1 张。
4. 填写产品特征，选择模特、场景和尺寸，点击「先生成 1 张样图」。点击图片放大查看，或切换原图比较。核对商品一致性后勾选确认。
5. 「继续生成套图」最多补充场景主图、侧面主图、背面主图，沿用已确认样图作为人物风格参考。缺少对应角度实拍时跳过。逐张处理，错误不会自动重试；手动重试会跳过当前样图下已成功的角度。取消会中断本机请求，但已提交给供应商的任务可能仍计费。
6. 「生成实拍细节图」无需 API，从标记为细节的素材取前 4 张（没有时使用产品图前 4 张），按原比例完整排入 800×1200 版面，可为每张填写标题。此步骤不重绘产品。AI 主图输出 PNG 1024×1024 或 1024×1536，支持单张下载和全部 ZIP。
7. 修改素材或参数会使样图确认失效；旧结果保留并显示设置版本。结果只在当前页面内存中，请在刷新或关闭前下载。AI 生成不能保证产品像素完全不变，应核对洗水、版型、口袋、抽绳等关键细节。

本机服务仅监听 `127.0.0.1`，不对局域网开放；密钥不发给前端，不写浏览器存储，静态文件采用白名单。测试使用模拟图片服务，未执行付费真实出图。API 字段依据 [OpenAI 图片编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)。

## GitHub Pages

仓库已有 `.github/workflows/deploy-pages.yml`。在仓库 Settings → Pages 将 Source 设为 GitHub Actions；合并到 `main` 后工作流自动发布，也可手动运行。所有静态资源使用相对路径，兼容 GitHub 项目页路径。GitHub Pages 不运行 Node 服务，线上页面的 AI 出图按钮在未连接服务时禁用，实拍细节排版仍可使用；当前 AI 出图入口通过本机启动器使用。

运行单元测试（Node.js 22+，AI 接口测试需要监听本机端口）：

```sh
node --test tests/*.test.cjs
```


单元测试覆盖 ZIP/目录导出、英文模板及单词换行、翻译输入校验、仅发送文案、额度、失败、取消、超时和缓存。浏览器检查使用模拟翻译响应，覆盖中英文五图生成、可编辑译文、原文保留、翻译失败和取消、长英文文件名、JPG/PNG ZIP、修改后禁用旧结果导出、原裁剪状态及小屏布局；不会在回归测试中发送真实文案到翻译服务。

批量工具测试覆盖尺寸适配、压缩、拼图、水印、背景连通区域、透明度、编码格式、七个工具的实际生成和导出、共享素材、旧结果失效、取消处理、损坏图片、菜单切换及手机布局。


## 在线分享版（每人使用自己的 API Key）

在线版入口为 `cloud-server.cjs`，与本机专用的 `ai-server.cjs` 分开。部署后页面和 API 使用同一 HTTPS 域名；使用者不需要安装 Node，直接打开网址即可。每位使用者在页面填写自己的 API Key，费用由该使用者的 API 账户承担。不要在云端设置站主的 `OPENAI_API_KEY`；在线服务不会读取它。

已提供 Render 的 `render.yaml`。在 Render 创建 Web Service，选择本仓库、Node 环境、Free 实例，构建命令 `node --check cloud-server.cjs`、启动命令 `node cloud-server.cjs`，健康检查 `/healthz`。Render 的 `RENDER_EXTERNAL_URL` 自动作为正式网址；其他平台需设置 `PUBLIC_ORIGIN=https://你的域名`，并提供 HTTPS 反向代理。不要带末尾斜杠。单实例运行，默认监听平台提供的 `PORT`。

在线版密钥保存在独立会话的服务器内存中，闲置一小时过期，可主动清除；页面刷新产生新会话，旧密钥不会提供给新页面。图片任务先提交，再查询进度，避免长请求被代理截断。最多同时处理 3 个任务，每个会话同时 1 个；完成图片暂存最多 5 分钟，总缓存最多 64 MB，达到上限会淘汰旧结果。结果不写磁盘。服务重启或休眠会清空密钥和任务，页面已收到的结果不受影响，但刷新前必须下载。此版本适合少量朋友试用，不提供长期云相册或任务恢复。

密钥与素材会经你的托管服务器转交 OpenAI，页面在填写前明确说明这一点。API 地区、账户权限和费用限制仍适用。免费 Render 会在闲置后休眠，下次访问需等待唤醒；免费额度及限制以 [Render 官方文档](https://render.com/docs/free) 为准。
